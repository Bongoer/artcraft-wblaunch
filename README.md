# ArtCraft Web Launcher (unofficial)

Original ArtCraft Launcher WebAssembly build on the homepage, with dedicated pages for the Craft App Suite.

- `/` - launcher homepage, showing the real ArtCraft Launcher WebAssembly app.
- `/launcher/` - unchanged ArtCraft Launcher WebAssembly release.
- `/apps/` - browser app directory.
- `/apps/photocraft/` - unchanged PhotoCraft WebAssembly release.
- `/apps/<app>/` - reserved pages for other Craft apps.

The web launcher is currently a catalog; its original app download links aren't rewritten.
Use the **Open web apps** button on the homepage to access the locally hosted browser apps.

Upstream: https://github.com/storytold/craft-launcher and https://github.com/storytold/photocraft.
All upstream notices and licenses in the release packages are retained.
Independent community deployment, not affiliated with the upstream ArtCraft project.
